# Profile and standing rules (template)

Copy to `profile.md` (gitignored) and fill in. The job-application skill reads
this before writing anything; facts here beat anything recalled from old letters.

## Contact and header
- Name on documents / legal name for forms
- Phone, email, address for forms, the location line shown in cover letters
- Link text rules (e.g. show the domain itself, never "Website")

## Education and dates (by role type)
- Co-op / internship wording and resume dates
- New grad / full-time wording and resume dates
- GPA as it should be reported on forms

## Claims: verified vs never claim
- Each project: what is true and can be claimed
- Words to avoid (e.g. "deployed" when it was only self-hosted)
- Skills you do not have yet (state as gaps only if a posting needs them)

## Voice
- Tone, salutation, usual letter shape, closer
- Audience filtering (what to leave out for which kind of role)

## Location
- Where you live; whether to ask before claiming willingness to relocate

## Inside addresses used before

## Resume
- Where the canonical source lives, page limit, date style
